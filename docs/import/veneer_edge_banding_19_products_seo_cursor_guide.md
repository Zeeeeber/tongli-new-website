# Veneer Edge Banding — 19 Products SEO + Cursor Publishing Guide

## 1. Summary

This package is prepared for publishing **19 Veneer Edge Banding products**.

- Category: `Veneer Edge Banding`
- Category slug: `veneer-edge-banding`
- URL pattern: `/products/veneer-edge-banding/[slug]`
- Image destination: `public/images/products/veneer-edge-banding/[slug]/`
- Data file: `src/data/products/veneer-edge-banding-products.ts`
- Detail template: `src/components/product/VeneerEdgeBandingDetailTemplate.tsx`

Important SEO/material rule:

**Do not use PVC, ABS, acrylic, plastic edge banding, or similar plastic-material keywords.**  
These products should be positioned as **natural wood veneer edge banding** and **engineered/recon wood veneer edge banding**.

## 5. Cursor Publishing Instruction

Copy this instruction into Cursor after placing the JSON and this guide in `docs/import/`.

```text
请读取：

docs/import/veneer_edge_banding_19_products_seo_cursor_guide.md
docs/import/veneer_edge_banding_19_products_data.json

本次目标：
发布 19 个 Veneer Edge Banding / Wood Veneer Edge Banding 产品到网站。

重要说明：
1. 这些产品的原材料是天然木皮或科技木皮。
2. 不要使用 PVC、ABS、acrylic、plastic edge banding 等塑料材质关键词。
3. 不要自行重写产品标题、SEO title、描述、tags、slug。
4. 严格使用 JSON 文件中的 SEO 数据。
5. 文件夹名称中的地名、平台词、阿里巴巴等信息不要进入英文产品标题。

原始图片目录：

C:\Users\Administrator\Desktop\网站合集图\产品发布\veneer edge banding

如果无法读取这个 Windows 路径，请提醒我把图片复制到：

_import/veneer-edge-banding-raw/

正式图片目录：

public/images/products/veneer-edge-banding/

执行顺序：

第一步：整理图片

1. 每个产品一个 slug 文件夹。
2. 根据 JSON 的 sourceFolder / oldFolderName 匹配原始图片文件夹。
3. 文件名中包含 (1)、（1）、１ 的图片优先作为首图 image-01。
4. 如果原始图片没有 (1) 标识，则按文件名自然顺序取第一张作为 image-01。
5. 其他图片按自然顺序命名为 image-02、image-03……
6. 保留真实扩展名，不要把 jpg 强行改成 png，也不要把 png 强行改成 jpg。
7. 不要删除原始图片。
8. 不要压缩图片。
9. 不要转换 webp。

第二步：发布产品数据

1. 创建或更新产品数据文件：
   src/data/products/veneer-edge-banding-products.ts

2. 使用 JSON 中的 19 个产品。
3. category 使用：
   Veneer Edge Banding

4. categorySlug 使用：
   veneer-edge-banding

5. featuredImage 使用对应 slug 文件夹中的 image-01。
6. gallery 根据真实存在的图片生成，不要写不存在的图片路径。
7. 每个产品必须保留：
   slug
   name
   productName
   h1Title
   seoTitle
   metaDescription
   shortDescription
   shortDesc
   tags
   imageAlt
   category
   categorySlug
   featuredImage
   gallery
   specs
   applications
   faqs
   overview

第三步：详情页路由

1. 创建或更新：
   src/app/products/veneer-edge-banding/[slug]/page.tsx

2. 使用当前已经修改好的：
   src/components/product/VeneerEdgeBandingDetailTemplate.tsx

3. URL 格式：
   /products/veneer-edge-banding/[slug]

4. generateStaticParams 包含全部 19 个 slug。
5. generateMetadata 使用 seoTitle 和 metaDescription。
6. slug 不存在时 notFound()。

第四步：同步页面

请同步：

1. /products/veneer-edge-banding 类目页
   - 显示 19 个正式产品
   - 产品卡片链接使用 /products/veneer-edge-banding/${product.slug}
   - 图片优先 featuredImage，其次 gallery[0]，最后安全占位图
   - 不显示旧占位产品

2. /products 总页
   - 左侧分类选择 Veneer Edge Banding 时显示这 19 个产品
   - All Products 包含这 19 个产品
   - 不重复显示产品
   - 不恢复旧 Features 筛选器

3. Veneer Edge Banding 详情页 Related Products
   - 从 19 个正式产品中读取
   - 排除当前产品
   - 显示 3 或 4 个
   - 链接使用 /products/veneer-edge-banding/${product.slug}

不要修改：
1. Natural Wood Veneer
2. Wood Veneer Panels
3. Engineered Wood Veneer
4. Melamine Board
5. 3D Wood Panels
6. Supporting Boards
7. Header / Footer
8. Home / About / Contact
9. sitemap / robots
10. 全局 SEO 配置
11. 表单功能
12. 产品详情页整体设计

完成后运行：

npm run build

并输出：
1. 修改了哪些文件
2. 发布了多少个 Veneer Edge Banding 产品
3. 19 个 slug 列表
4. 每个产品图片数量
5. 是否使用了 PVC/ABS/plastic 关键词，如果有必须删除
6. /products/veneer-edge-banding 是否显示 19 个产品
7. Products 总页选择 Veneer Edge Banding 是否显示 19 个产品
8. Related Products 是否正常
9. npm run build 是否通过

不要直接 git add .。
build 通过后，等待我确认再进行白名单提交。
```

## 7. Notes for Image Sorting

- If a source filename includes `(1)`, `（1）`, or `１`, use that image as `image-01`.
- If no `(1)` image exists, use the first file in natural filename order as `image-01`.
- Preserve the real extension.
- Do not delete source images.
- Do not compress or convert images in this step.
